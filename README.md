# Contact Book Using Python

## Project Overview

The Contact Book is a menu-driven Python application that allows users to manage contact information using dictionaries.

It provides basic contact management operations such as adding, searching, updating, and deleting contacts.

## Features

- Add new contacts with names and phone numbers.
- Search contacts by name.
- Update existing contact details.
- Delete contacts.
- Display all available contacts.
- Simple interactive menu.

## Technologies Used

- Python 3
- Dictionary
- Conditional Statements
- Loops
- Functions

## How to Run

1. Clone the repository.

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder.

```bash
cd Contact-Book
```

3. Run the program.

```bash
python3 contact_book.py
```
